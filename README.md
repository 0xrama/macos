# macOS Portfolio Website

A portfolio website that simulates the macOS GUI interface, built with modern web technologies. This project is heavily inspired by and credits [Renovamen's playground-macos](https://github.com/Renovamen/playground-macos).

![Portfolio Demo](https://portfolio.zxh.io/images/screenshot.png)

## 🚀 Tech Stack

- React
- TypeScript
- Zustand (State Management)
- UnoCSS
- Vite

## 🛠️ Development

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed on your system.

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/macos-portfolio.git

# Navigate to project directory
cd macos-portfolio

# Install dependencies
pnpm install
```

### Development Server

```bash
# Start development server with hot reload
pnpm dev
```

### Production Build

```bash
# Build for production
pnpm build
```

The built files will be generated in the `dist` folder.

## 🎨 Features

- Realistic macOS interface simulation
- Light/Dark mode support
- Interactive desktop environment
- Responsive design
- Battery status integration (uses Battery API where supported)
